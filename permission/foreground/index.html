App: Filegrab (com.kmate.filegrab) — an offline file manager for Android.

Declared task type: local processing — other.

What the service does

Copying, moving, deleting and bulk-renaming files inside the user's own storage. The user starts the operation explicitly, sees a progress bar with a running count while it works, and is told when it finishes.

The foreground service exists so that a transfer the user has started is not killed halfway through when they leave the screen. A file operation that stops silently in the middle leaves the user with a partly copied folder and no way to know which files made it.

What it is not

  • No network of any kind. The app has no INTERNET permission and no networking code, so this is never a background upload, download or sync with a server.
  • Not periodic or automatic. The service runs only while an operation the user started is still running, and stops as soon as it is done.
  • Nothing is collected, and nothing leaves the device.

StepWhat it shows
1A folder of 3,000 files. The user long-presses one file and taps Select all — the title shows "3000件を選択" (3,000 selected).

Step 4 is the point: the work the user asked for survived leaving the app. Android's own ongoing notification for this service is not shown in the clip, only because the device's notification shade also holds the owner's private notifications.

何をしているか

端末の中のファイルの複製・移動・削除・一括リネームです。始めるのは使う人で、進み具合は件数つきの帯で見え、終わったら知らせます。申告したタスクの種類はローカル処理（その他）です。

前景サービスにしているのは、始めた移動が途中で黙って止まらないようにするためです。途中で切られると、どこまで移ったのか分からないフォルダだけが残ります。

やらないこと

  • 通信は一切ありません。 INTERNET 権限を持たず、通信の仕組みもないので、裏で送る・受け取る・同期することはありません
  • 定期実行もしません。 使う人が始めた作業が続いている間だけ動き、終われば止まります
  • 集めるものはなく、端末の外へ出るものもありません

動画の中身
