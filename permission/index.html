App: Filegrab (com.kmate.filegrab) — an offline file manager for Android.

Why the app needs All files access

The core feature of Filegrab is searching the whole device for files: by name, format, date, size, and by text inside documents. A file manager has to reach files the user did not pre-select.

The Storage Access Framework cannot provide this:

  • SAF has no device-wide search across folders. Device-wide search is this app's core feature.
  • SAF requires the user to pick a folder before anything can be shown, so the app is not usable right after launch.
  • Recursive traversal through SAF is orders of magnitude slower than real paths, and cannot meet this app's speed requirement.

File contents are never sent anywhere. The app does not hold the INTERNET permission and has no networking code at all.

この権限が必要な理由

Filegrab の中核機能は、端末内のファイルの横断検索（名前・形式・日付・サイズ・文書内の文字）です。ファイルマネージャーである以上、ユーザーがあらかじめ選んだフォルダの外にも届く必要があります。

  • SAF では端末全体を対象とした横断検索ができません。横断検索はこのアプリの中核です
  • SAF はフォルダを先に選ばせる作りで、起動してすぐ使えません
  • SAF 経由の再帰的な走査は実パスに比べて桁違いに遅く、速度の要件を満たせません

ファイルの内容を外部に送ることはありません。INTERNET 権限を持たず、通信する仕組み自体がありません。
