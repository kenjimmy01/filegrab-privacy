App: Filegrab (com.kmate.filegrab) — an offline file manager for Android.

Why the app needs this permission

An APK is an ordinary file sitting in the user's storage, and opening files is what a file manager is for. When the user taps an APK, Filegrab hands it to the Android package installer.

Without REQUEST_INSTALL_PACKAGES, nothing happens at all: Android drops the request without an error, so to the user that one file type simply looks broken in an app whose whole job is opening files.

What the app does not do

  • It never installs anything itself, and never silently. It only passes the file to the system installer, which asks the user every single time.
  • It cannot download an APK. The app has no INTERNET permission and no networking code, so the only APKs it can open are files already on the device.
  • It does not sideload, update or replace apps in the background, and has no app store or distribution feature of any kind.

この権限が必要な理由

APK は端末の中にある普通のファイルで、ファイルを開くのがこのアプリの仕事です。押されたら、Android の導入画面へ渡します。

この宣言が無いと、押しても何も起きません。OS はエラーも返さずに黙って弾くので、使う人からは「この形式だけ壊れている」ように見えます。

やらないこと

  • 自分では入れません。黙って入れることもありません。 OS の導入画面に渡すだけで、入れるかどうかは毎回その画面で人が決めます
  • APK を落としてくることはできません。 INTERNET 権限を持たず通信の仕組みが無いので、開けるのは端末にすでにあるファイルだけです
  • 裏でアプリを入れ替えることはせず、ストアや配布の機能も持ちません

動画の中身
